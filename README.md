# Xendra — download

Página e releases públicas do instalador do Xendra.

- Página: https://cvjxendra.github.io/xendra-download/
- Releases: https://github.com/cvjxendra/xendra-download/releases/latest

Este repositório não contém o código-fonte. O instalador é um `.exe` versionado,
assinado com certificado próprio da Xendra (autoassinado). O Windows pode mostrar
fornecedor desconhecido; isso é esperado neste canal.

Não envie o executável como anexo. Use o link desta página.
