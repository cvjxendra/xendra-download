Baixe o instalador somente por esta página oficial. O Windows pode analisar o arquivo na primeira execução.

Baixar o Xendra para Windows Notas da versão SHA-256

O instalador atual é assinado pela Xendra com certificado próprio (autoassinado). O Windows pode mostrar “fornecedor desconhecido” ou “O Windows protegeu o computador”. Isso é esperado.

O editor esperado é Xendra Software.

Se o Windows avisar

  1. Se a tela “O Windows protegeu o computador” aparecer, selecione “Mais informações” e confira se o editor é Xendra Software.
  2. Se o nome for esse, selecione “Executar assim mesmo”. Se aparecer outro editor, não prossiga e entre em contato com o suporte.
