Baixar o Xendra para Windows SHA-256

Se o Windows avisar

  1. Se a tela “O Windows protegeu o computador” aparecer, selecione “Mais informações” e confira se o editor é Xendra Software.
  2. Se o nome for esse, selecione “Executar assim mesmo”. Se aparecer outro editor, não prossiga e entre em contato com o suporte.
